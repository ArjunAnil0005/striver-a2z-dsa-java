mark it done when you can solve it without looking at a solution. The numbers
are practice order within each topic, not global A2Z sheet indices.

## Before checking a solution

For each problem, write down the input and output, try a brute-force approach,
check edge cases, then improve the approach and note its time and space
complexity. The starter files are intentionally unfinished.
